# <span style="color:green">스프링 컨테이너</span>
자바 객체의 생명 주기를 관리하며, 생성된 자바 객체들에게 추가적인 기능을 제공  
애플리케이션 컨텍스트는 스프링 컨테이너와 유사한 말

# <span style="color:green">Java SE</span>
- 자바 언어라고 하는 대부분의 패키지가 포함된 에디션
- Java SE의 API는 자바 프로그래밍 언어의 핵심 기능들을 제공, 따라서 JDBC아 GUI, 네트워크 등 각종 API를 이용해서 개발 가능
- 데스크톱, 서버, 임베디드 시스템을 위한 표준 자바 플랫폼

# <span style="color:green">Java EE</span>
- Java EE 플랫폼은 Java SE 플랫폼을 기반으로 그 위에 탑재
- WEB 개발을 하기 위해서 Java EE로 개발을 진행
- 웹 프로그래밍에 필요한 기능을 다수 포함
  - JSP, Servlet, JDBC 등
- 자바를 이용한 서버측 개발을 위한 플랫폼
